# Smart Factory Monitoring Dashboard

## Overview

A Smart Factory Monitoring Dashboard developed using Python, Pandas, and Streamlit for monitoring industrial machine health.

The dashboard visualizes sensor data, tracks machine performance, and detects abnormal operating conditions.

## Features

* Real-time style dashboard interface
* Temperature monitoring
* Vibration monitoring
* Current monitoring
* Interactive charts
* Fault detection alerts
* Machine health status indicator

## Technologies Used

* Python
* Pandas
* Streamlit

## Project Structure

smart-factory-monitoring-dashboard

├── app.py

├── sensor_data.csv

├── requirements.txt

└── README.md

## How to Run

Install dependencies:

pip install -r requirements.txt

Run application:

streamlit run app.py
